# HitBox Expander

## Installation
1. Install Fabric Loader 0.15.0+
2. Install Fabric API
3. Put hitboxexpander-1.0.0.jar in mods folder

## Controls
- **H** - Toggle mod
- **[** - Decrease hitbox size
- **]** - Increase hitbox size

## Config
File: `config/hitboxexpander.json`

## Building
```bash
./gradlew build
